# Concept
Using the TCPdump tool
# Notes
* TCPdump is a command-line packet sniffer
* requires root privileges (sudo) to run
* installed by default on many Linux distros
* TCPdump arguments:
  * `D` Will display any interfaces available to capture from.
  * `i` Selects an interface to capture from. ex. -i eth0
  * `w` write to a file
  * `r` reads from a file
  * `X` display in ASCII and hex
