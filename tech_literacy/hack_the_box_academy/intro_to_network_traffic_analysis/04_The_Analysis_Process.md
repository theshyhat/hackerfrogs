# Notes
* two types of traffic analysis: active and passive
  * active (in-line)
    * requires permission
    * requires a capture tool
    * requires in-line placement
    * requires network tap or multiple NICs
  * passive
    * requires permission
    * requires a mirrored port
    * requires a capture tool
